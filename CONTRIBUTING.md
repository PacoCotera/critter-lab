# Contributing

This repository is the authoritative product source. Start with the [documentation map](docs/README.md), then use the specifications or builder guide for your change.

Open a focused issue or pull request explaining the problem, proposed result and relevant evidence. Update affected specifications alongside behavior. Use checks proportionate to the change; hardware performance claims need physical measurements.

Submit original material, or material you have permission to contribute, under the applicable license in [LICENSING.md](LICENSING.md), unless expressly agreed otherwise. Contributors retain their copyright. Contributing does not assign copyright or automatically grant permission for unrelated proprietary relicensing.

Keep player explanations, design proposals, technical requirements and build instructions separate. Use short, descriptive sections and link to the authoritative rule instead of repeating it. Images should explain the adjacent content, include useful alt text and identify concepts versus measured or implemented results. Preserve recognizable device geometry and creature identity; do not use a new illustration to imply a new feature.

Identify third-party sources and licenses. For artwork, preserve editable sources or generation inputs and provenance where available. For hardware, provide editable design sources rather than only screenshots. Do not submit credentials, player data or private operational records.

Upstream contributions are welcome, but the licenses do not compel a pull request or require maintainers to accept one.
