# Product status

Current foundation: Pip is an accepted qualitative phenotype example spanning the five genomic layers and eleven dimension families. The [genetic engine/locus-library proposal](specs/genetics.md#proposed-genetic-engine-and-content-library) combines reusable content definitions, algorithmic generation/expression/validation and LLM-assisted authoring. The approved [bounded contract](specs/genetic-engine.md) now has an executable [Pip proof and report](prototype/genetics/README.md), feeding the same research-workbench design. It covers 243 valid combinations, explicitly sample-supported founder candidates, traced qualitative expression, partial research disclosure and one exact cross. Focused checks pass; report regeneration is deterministic. A complete engine and production authoring system are not implemented. The live host demo still uses an older, separate genetics experiment; it does not implement the Pip contract.

Critter Lab is in system and game design. The public repository contains the product specifications, original hardware concepts and runnable host experiments.

| Stage | Current evidence |
| --- | --- |
| Game and system design | Research, genetics, player ownership and device responsibilities documented; detailed rules remain open |
| Local software | Separate breeding/share, founder, transfer and saved-record experiments with authored data |
| Creature generation | Pipeline specified; no complete genome-to-art or content-management service |
| Physical kit | Concept references; no production firmware, PCB, editable cases or validated charging assembly |
| Hosted game | No deployable public production backend or companion app |

The V1 research structure, creation terms and expedition flow are accepted. The [Lab collection-to-discovery study](design/genome-workbench/README.md) is approved as a static composition and interaction direction within Playful Pixel Lab. It is not implemented UI or a complete Probe-to-incubation journey. Final critter art and missing screen states remain open.

Current design work is [gathering and progression](design/probe-sampling.md): three Probe-prepared research resources, rare findings enabling retained research methods, and discoveries proportional to progress. Those directions are accepted; resource names, exact recipes, drop rates and the proposed Probe tier/range/capacity/detection structure remain open. The [connected research model](design/research-and-creation.md) supplies the entity map, partial-genome collection and shared inventory. Full decoding precedes incubation.

Material studies are V1 placeholders; final release requires broader meaningful study types. Exact content mappings, console-only acquisition details, everyday care, temporary offline reconciliation and physical feasibility remain open. The [sample-to-critter contract](specs/sample-to-critter-contract.md) connects research and creation; a [player introduction](docs/players/README.md) explains the intended experience.

[Build coverage](BUILD.md) is the component inventory. [Run the experiments](docs/builders/getting-started.md) for available software. Source snapshots and compatibility are described in [versions](releases/README.md).
