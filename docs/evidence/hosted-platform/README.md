## Limits

The HTTPS origin has separate browser storage from localhost. Existing records require explicit recipe export/import; existing local data remains retained. Manually returned pet bitmaps and linked metadata remain a separate browser proposal store and are not automatically migrated or remotely generated.

The bench is an incomplete developer prototype:111 defined copy contracts and six draft candidates, five branches without executable domain contracts, partial consumers, limited organism range and unresolved source fur/ear/paint craft. Eleven headings are not complete eleven-layer implementation. Hosting does not approve pet masters, add animation, complete genome sharing or prove hardware/biology.

The website describes the intended future product as well as the current playable preview. The separately assigned Critter Lab website refresh will review retained concepts, missing/misrepresented future features and the distance from the brief; it must preserve these deployed routes.
