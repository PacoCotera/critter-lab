# Documentation

Choose a starting point for what you want to do.

| Reader | Start here | What it contains |
| --- | --- | --- |
| New player | [Meet Critter Lab](players/README.md) | The devices, the discovery loop and a few useful words |
| Design reviewer | [Design and visual references](../design/README.md) | Intended experiences, reference images and choices still being explored |
| Builder or developer | [Run the experiments](builders/getting-started.md) | Setup, local routes, saved data and troubleshooting |
| Technical contributor | [Specifications](../specs/README.md) | Game rules, genetics, architecture and device boundaries |

[Build coverage](../BUILD.md) lists available source and missing components. [Product status](../STATUS.md) distinguishes working experiments from the planned game. [Versions](../releases/README.md) explains compatibility; [contributing](../CONTRIBUTING.md) explains how to propose changes.

Player explanations describe the intended experience. Design proposals explore choices. Specifications define rules and contracts. Builder instructions describe operations supported by the available source. None substitutes for another.
