# Critter Lab website

A static product introduction inspired by Playdate's playful typography and product storytelling, using the established sage, stone, charcoal and restrained orange device palette. The page follows the current three-object direction in [devices](../specs/devices.md): Companion, home Lab and caddy. Hardware images are retained concept studies, not physical evidence or final designs. The linked Lab preview is a limited software slice.

The game explanation connects exploration, research, founder creation, selective breeding, crafting and habitats. The genomics section follows the [accepted genetics framework](../specs/genetics.md), distinguishing it from the bounded [Pip proof](../specs/genetic-engine.md). Its P/p × P/p worked cross is a conditional single-locus illustration, not a live-game forecast. Inherited information, expressed phenotype and acquired lifetime state stay distinct. Owner requested concept-matched colors and a fuller explanation of advanced genomics on 29 September 2026; no mechanics or genetic rules change in this website revision.

Serve `dist/` with a local static HTTP server. No dependencies, build step, backend, purchases or signup service are required. Device tabs support arrow keys, Home and End; without JavaScript, all device descriptions remain visible. FAQs use native disclosures. Artwork is reused from `design/lab-controls/combined-family-caddy-v3.png` and `combined-companion.png`; the original reference files remain intact.

Website software and eligible artwork follow the [project licensing](../LICENSING.md). Brand identity follows [branding and attribution](../BRANDING.md).
