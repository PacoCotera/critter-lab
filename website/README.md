# Critter Lab website

Static product introduction using the established sage, stone, charcoal and restrained orange device palette. **Critter Lab** is the project name; **Beecho / Beechos** remain creature names. Original references and native captures retain their original lettering and provenance.

The site carries the whole intended journey: Companion gathering and return → explicit Lab acceptance → genome research and configured creation → retained residents, bonding, training and selective breeding → truthful ambient Caddy summaries and paper records. The Lab is the visual living-world workbench; one combined Companion has Probe/Cargo/Companions modes; the Caddy is their shared charging and printing home. Device-hosted setup and local core play without a required phone or Cloud Pass remain product direction. See [gameplay](../specs/gameplay.md), [devices](../specs/devices.md), [experience](../specs/experience.md) and [local/cloud boundaries](../specs/cloud-sync.md).

Future intent, actual software, retained visual concepts and physical evidence have separate labels. The connected game simulator retains a bounded authored creature family. The separate genome bench supports versioned authoring, constructed source creatures, a factual short art brief and explicit local retention of returned pet proposals against their exact source. Its 111 copied pairs, six unsupported drafts and eleven genomic headings remain incomplete: five branches lack executable contracts and other consumers remain missing. Broad organism variety, complete-genome sharing, accepted pet art, animation and game-incubation integration remain unfinished. [The authoring contract](../design/anatomical-source-prototype/compositional-contract.md) and [workbench guide](../prototype/generator-workbench/README.md) own the details. Marketing evidence links use the public hosting branch containing these files; they do not imply a merge into `main`.

Serve `dist/` with a static HTTP server; no dependencies or build step. Existing device tabs support arrows, Home and End; without JavaScript all device descriptions are visible. FAQs and the science detail use native disclosures. The website implements no game behavior or simulator controls.

The [platform gateway](../prototype/platform-server/README.md) mounts this website at `https://critterlab.basicberry.com/`, the genome workbench at `/genome/` and the simulator at `/sandbox/`. Both prototypes are visible destinations. Their processes and release identities remain separate; gateway source integration alone does not establish activation.
