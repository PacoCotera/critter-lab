# Critter Lab website

Static product introduction using the established sage, stone, charcoal and restrained orange device palette. **Critter Lab** is the project name; **Beecho / Beechos** remain creature names.

The site presents the intended journey: Companion gathering and return → explicit Lab acceptance → retained research and configured creation → one saved individual, bonding, training and selective breeding → truthful Caddy summaries and paper records. One combined Companion has Probe/Cargo/Companions modes; the Lab owns the visual living-world workbench; the Caddy is their shared charging and printing home. Device-hosted setup and local core play without a required phone or Cloud Pass remain direction. Product authority: [gameplay](../specs/gameplay.md), [devices](../specs/devices.md), [experience](../specs/experience.md) and [local/cloud boundaries](../specs/cloud-sync.md).

## Software destinations and boundaries

The existing [platform gateway](../prototype/platform-server/README.md) mounts this website at `https://critterlab.basicberry.com/`, the separate genome workbench at `/genome/` and simulator at `/sandbox/`. The website changes no game or workbench behavior. Serve `dist/` with a static HTTP server; no website dependency or build step. Existing device tabs support arrows, Home and End; without JavaScript all device descriptions remain visible. Native disclosures supply FAQs and detailed information.

The simulator implements a bounded authored creature family and parts of the illustrated loop; its interface remains less visually developed. Use depicted physical directions, workspace keys, Confirm and Back. Screen pixels are not controls. Wireless exchange and printing remain simulated. Saved game progress persists within an unchanged native release; website-only activation preserves that release and saves.

The genome bench carries114 copied pairs, six drafts and eleven genomic headings, with four domains still lacking executable contracts. It remains a separate authoring experiment, not a way to create game residents. Full genomic coverage, broad organism variety, sharing, accepted pet art and animation are unfinished. [Authoring contract](../design/anatomical-source-prototype/compositional-contract.md) and [workbench guide](../prototype/generator-workbench/README.md) own the current details. Product evidence links use the public hosting branch containing those sources.

Standalone and optional Cloud Pass remain intended capabilities; availability, prices and purchase flows are not announced. Host software and concept pictures cannot establish physical readability, radio, sensors, enclosure fit or fun. [Licensing](../LICENSING.md) and [branding](../BRANDING.md) apply.
