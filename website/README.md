# Beecho Lab website

Static product introduction using the sage, stone, charcoal and restrained orange device palette. **Beecho / Beechos** are the creature names; Beecho Lab remains the current website label while the main product name is being reconsidered. Critter Weaver is a candidate, not a selected replacement. Existing repository and hosting URLs remain in use.

The connected story introduces the home Lab (Raspberry Pi 4 development reference), one combined Companion with Probe/Cargo/Companions modes, and the shared charging/printing dock or Caddy. No fourth Probe is implied. The marketing copy keeps the wider genomics, standalone and optional Cloud Pass directions while distinguishing the current local software prototype from future services, physical hardware, capture/training and habitat ecology. See [product status](../STATUS.md) and [device specifications](../specs/devices.md).

Serve `dist/` with a static HTTP server; no dependencies or build step. Existing device tabs support arrows, Home and End; without JavaScript all device descriptions are visible. FAQs and the science detail use native disclosures. No game behavior or simulator controls are implemented by this website.
