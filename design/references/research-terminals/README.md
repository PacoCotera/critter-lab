# Research-terminal references

Supplied by the owner on 26 September 2026 to steer screen exploration. Originals are preserved and hashed in the asset manifest. These references inform instrument character, panel organization, consistent typography and meaningful visual studies. Their text, scientific claims, measurements, window controls and hardware are not game requirements.

The amber terminal and color terminal are the primary comparison references. The hexagonal composition explores a different spatial organization; it does not establish a navigation model. Exact duplicate input images are stored once.

See the [screen design standard](../../screen-design-standard.md). New explorations require review; none of these images constitutes final screen or hardware acceptance.
